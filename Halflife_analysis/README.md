# Half-life Analysis Pipeline (Ribo-seq / RNA-seq)

Analysis pipeline for mRNA half-life estimation in *E. coli* K-12, comparing EV (empty vector) and WT (wild-type) conditions. The pipeline spans raw read QC → alignment → gene counting → TPM normalization → half-life calculation → visualization → differential expression.

## Directory Structure

```
Halflife_analysis/
├── 00_fastp.bash                  # Raw FASTQ quality control
├── 01-alignment-double.bash       # Bowtie2 alignment to E. coli K-12
├── 02-Readcount.py                # Merge mRNA + ncRNA count matrices
├── 03_Normalization/
│   └── tpm_boxplot.R              # TPM calculation + boxplot
├── 04_halflife/
│   ├── calculate_half_life.R      # Half-life estimation (NLS + LM)
│   ├── plot_half_life_annotated_log2.R  # Violin by Condition + motif
│   ├── plot_half_life_density.R   # Density with peak annotations
│   ├── plot_half_life_ecdf.R      # ECDF: EV vs WT
│   ├── plot_half_life_log2_EV_vs_WT.R  # Violin: EV vs WT
│   └── plot_heatmap_v2.py         # Heatmap of top 50 half-life diff genes
├── deseq/
│   ├── run_deseq2.R               # DESeq2: WT vs EV (0min)
│   ├── run_go_enrichment_combined.R    # GO enrichment barplot
│   ├── run_go_enrichment_gradient.R    # GO enrichment gradient plot
│   └── sample_correlation_heatmap.R    # Sample correlation heatmap
├── reference/
│   ├── Escherichia_coli_...dna.chromosome.Chromosome.fa  # Reference genome
│   ├── Escherichia_coli_...Chromosome.gff3               # Gene annotation
│   ├── Escherichia_coli_...Chromosome.gtf                # Gene annotation (GTF)
│   ├── build_index.sh            # Build Bowtie2 index
│   └── README.md                 # Reference data sources
├── .gitignore
└── README.md
```

## Pipeline Overview

```
00_fastp.bash                  Raw FASTQ QC (fastp)
       │
01-alignment-double.bash       Bowtie2 alignment to E. coli K-12 genome
       │
02-Readcount.py                Merge mRNA + ncRNA gene count matrices
       │
03_Normalization/
└── tpm_boxplot.R              TPM calculation + boxplot per sample
       │
04_halflife/
├── calculate_half_life.R      NLS/LM fitting of exponential decay → half-life
├── plot_half_life_*.R         Violin / density / ECDF plots
└── plot_heatmap_v2.py         Heatmap of top 50 genes by half-life difference
       │
deseq/
├── run_deseq2.R               DESeq2 differential expression (WT vs EV, 0 min)
├── sample_correlation_heatmap.R  Sample-to-sample Pearson correlation
├── run_go_enrichment_combined.R  GO enrichment barplot (BP + CC + MF)
└── run_go_enrichment_gradient.R  GO enrichment gradient (by -log10 p-value)
```

## Expected Input Data Layout

Scripts expect the following directory structure **one level above** this repository root (`../`):

```
../
├── RawData/                    # Raw FASTQ files (paired-end, *_1.fq.gz / *_2.fq.gz)
│   └── <sample>/
├── UCSC_db/                    # External data (not in this repo)
│   └── gene_tpm_with_motifs.csv   # TPM matrix for half-life calculation
├── 02-Readcount/               # Gene count matrices (generated by 02-Readcount.py)
│   ├── merged_gene_counts_with_annotations.csv
│   └── merged_gene_counts_with_annotations_ncRNA.csv
├── half_decay/                 # Half-life results (generated by calculate_half_life.R)
├── 00-QC/                      # QC outputs (generated)
├── 01-alignment/               # Alignment outputs (generated)
└── 03-Visualization/           # Heatmap outputs (generated)
```

The reference genome FASTA and GFF annotation are provided in `reference/`. Build the Bowtie2 index before running Step 1:
```bash
cd reference/ && bash build_index.sh
```

## Execution Order

All scripts are run from the `Halflife_analysis/` root directory.

| Step | Script | Input | Output |
|------|--------|-------|--------|
| 0 | `bash 00_fastp.bash` | `../RawData/` | `../00-QC/` |
| 1 | `bash 01-alignment-double.bash` | `../00-QC/cleaned/`, `reference/Ecoli` | `../01-alignment/` |
| 2 | `python 02-Readcount.py` | `../02-Readcount/` (2 CSVs) | `../02-Readcount/merged_gene_counts_final.csv` |
| 3 | `Rscript 03_Normalization/tpm_boxplot.R` | `../../02-Readcount/` | `../output/` |
| 4a | `Rscript 04_halflife/calculate_half_life.R` | `../../UCSC_db/gene_tpm_with_motifs.csv` | `../../half_decay/` |
| 4b | `Rscript 04_halflife/plot_half_life_*.R` | `../../half_decay/` | `../output/` |
| 4c | `python 04_halflife/plot_heatmap_v2.py` | count + half-life data | `../../03-Visualization/` |

## Notes

- **Sample naming convention**: Column names use the format `<Replicate>_<Condition>_<Time>_<ID>` (e.g., `A1_WT_0min_1`).
- **Reference genome**: *Escherichia coli* str. K-12 substr. MG1655. The Bowtie2 index prefix is `Ecoli`. Update `ref_dir` and `ref_prefix` in `01-alignment-double.bash` for other genomes.
- **GO annotation**: Uses `org.EcK12.eg.db` — specific to *E. coli* K-12. Change this package for other organisms.
- **"omin" typo**: Several scripts correct a column name typo (`omin` → `0min`) inherited from the upstream data source.
- **Half-life calculation**: Uses NLS (exponential decay) with LM fallback on log-transformed data. `half_life = ln(2) / k`, where k is the decay rate constant. Input is a TPM-normalized expression matrix.
